## 1. Admin Configuration Guide

Access the manager via **Addons -> Cloudflare Manager**.

### A. Global Configuration
- **Master API Token**: Enter your Cloudflare Global API Token or a Scoped Token with  for `Zone:Edit`, `Account:Edit`, and `DNS:Edit`.
- **Master Account ID**: Found in your Cloudflare dashboard URL (the alphanumeric string after `/dash/`).
- **Pro Addon ID**: The ID of the WHMCS Addon that unlocks "Pro" features. Any client holding this addon (Status: Active) will get full access to BYOT and Dedicated modes.

### B. DNS Template Manager (The "Core" Logic)
This table defines which records are created automatically when a domain is first added.
- **Type**: Choose A, CNAME, MX, or TXT.
- **Name**: Use `@` for the root domain or specify a subdomain (e.g., `www`).
- **Content**: Use dynamic variables:
    - `{ip}`: Automatically replaced with the Hosting Server's IP address.
    - `{domain}`: Replaced with the client's domain name.
- **Proxied**: Toggle the Cloudflare Proxy (Cloud icon) on or off for that specific record.

## 2. Client Area Features

### A. Cloudflare Center (Global Dashboard)
Located under **Services -> Cloudflare Center**.
- **Unified List**: Displays all active domains in the client's account.
- **Filter**: Use the search bar to find specific domains instantly.
- **Manage Button**: Quick access to the individual domain manager.

### B. Individual Domain Manager
Accessed via **Domain Manager -> example.com -> Cloudflare Manager**.
- **Managed Mode (Free)**: Standard for all active domains. Automatically provisions the zone using Admin templates.
- **Pro Tier Banner**: Appears for users on the free tier, encouraging them to upgrade to unlock advanced features.

#### Button Functions:
- **Purge Cache**: Immediately clears the Cloudflare cache for the entire zone.
- **Add Record**: Simple form to add `A`, `CNAME`, `MX`, or `TXT` records.
- **Delete Record (Trash Icon)**: Removes the DNS record from Cloudflare permanently.
- **Under Attack Mode (Toggle)**: Enables high-level DDoS protection if the site is being targeted.
- **Development Mode (Toggle)**: bypasses the cache for 3 hours (Locked for Free users).

## 3. Technical Notes
- **Provisioning**: Logic is triggered the first time a user visits the "Manage" page for an active domain.
- **Tier Sync**: The system checks in real-time if the user has the required addon ID to unlock "PRO" mode.
