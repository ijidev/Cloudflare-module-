# Cloudflare WHMCS Module v2.0 - Operations Guide

Welcome to the comprehensive operations guide for the Cloudflare WHMCS Module v2.0. This document provides detailed instructions on how to use the module effectively, understand its core features, and manage your client's domains.

---

## 1. Architectural Modes

This module offers three distinct architectural deployment modes to cater to different security and control requirements.

### Managed Core (Included in Free & Pro)
**How it works:** All client domains are provisioned and proxied directly through the Master Cloudflare Account configured by the Administrator. 
- **Benefits:** Zero friction for clients. They do not need to create or manage a Cloudflare account. They manage their DNS, caching, and security toggles directly from your WHMCS portal.
- **Downsides:** The client does not have direct login access to Cloudflare.com.
- **Ideal for:** Standard shared hosting clients who want protection without complexity.

### Dedicated Sub-Account (Pro Tier Only)
**How it works:** The module utilizes the Cloudflare Tenant API to automatically provision a completely isolated sub-account under your Enterprise Master Account. It uses the client's WHMCS registered email address.
- **Benefits:** The client can log into Cloudflare.com directly to manage advanced settings, but you (the Host) retain administrative API control and billing oversight. They benefit from an isolated security perimeter.
- **Downsides:** A Cloudflare account must *not* already exist for that email address. Requires the Host to have Cloudflare Enterprise Partner (Tenant) privileges.
- **Ideal for:** Premium clients, agencies, or dedicated server clients requiring advanced control.

### BYOT - Bring Your Own Token (Pro Tier Only)
**How it works:** The client brings their own API token generated from their personal Cloudflare account and inputs it into the WHMCS portal.
- **Benefits:** 100% administrative control remains with the client. They can use any pre-existing Cloudflare account.
- **Downsides:** Requires manual setup (generating the token) by the client.
- **Ideal for:** Advanced developers or clients migrating existing infrastructure.

## 2. Client Area Features & Navigation

The client interface has been completely overhauled in v2.0 to provide a premium, modern experience.

### The Dashboard (Cloudflare Manager)
Clients can access the main dashboard via the primary **Services -> Cloudflare Manager** navigation menu.
- **Overview:** Displays aggregate statistics (Total Domains, Account Tier).
- **Architecture Guide:** Educates the client on the three available modes.
- **Pro Configuration:** (Pro users only) Allows clients to switch between Managed, Dedicated, and BYOT modes dynamically.
- **Domain Assets:** A searchable table listing all active domains, their current infrastructure routing, and quick-access management buttons.

### Domain Management (`Manage` Interface)
Accessible via the dashboard or directly from the WHMCS Domain Details sidebar.
- **Migration Walkthrough:** If a domain is not yet on your Cloudflare infrastructure, the module intelligently detects this and displays a 3-step migration guide, ensuring zero-downtime transfers.
- **DNS Record Manager:** A clean, inline-editable DNS table supporting A, CNAME, MX, and TXT records. Changes are pushed instantly to Cloudflare via the API.
- **Quick Toggles:** 
  - **Purge Cache:** Instantly clears the Cloudflare cache for the zone.
  - **Under Attack Mode:** Toggles Cloudflare's maximum security challenge page.
  - **Development Mode / Pause:** Temporarily bypasses Cloudflare routing.

## 3. Automated Pro Tier Upgrades

The v2.0 module completely eliminates manual administration for the "Pro" tier.

**How to Upgrade Clients:**
Clients can upgrade to the Pro tier in two ways:
1. **Standalone Invoice:** By clicking the "Upgrade Now" button in the client area, the module automatically generates a WHMCS invoice for the upgrade.
2. **Product Purchase:** By purchasing any WHMCS Product or Addon that contains the phrase **"Cloudflare Pro"** in its name.

**Automated Activation:**
The module includes a background hook (`hooks.php`). As soon as an invoice containing the Pro upgrade is marked as **Paid**, the system immediately updates the client's database status, instantly unlocking BYOT and Dedicated modes in their dashboard.

## 4. Troubleshooting & Self-Healing

- **Database Errors:** The module includes a "Self-Healing" mechanism. If the database tables are ever accidentally dropped, navigating to the module will automatically reconstruct the schema without data loss.
- **API Errors / Blank Pages:** The module now gracefully handles Cloudflare API timeouts or permission errors using SweetAlert2 popups and safe error catching, preventing WHMCS fatal crashes.
- **Migration Stuck:** If a client claims they cannot see their DNS records, ensure they have completed the Migration Walkthrough and removed the domain from their previous external Cloudflare account.
