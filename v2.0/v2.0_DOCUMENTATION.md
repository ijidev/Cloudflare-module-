## 1. Initial Setup & Activation

Before using the module, you must activate the addon and configure permissions:

1. **Activate the Addon**: Go to **Setup -> Addon Modules**. Find **Cloudflare Manager** and click **Activate**.
2. **Set Permissions**: Click **Configure** for the Cloudflare Manager addon. Check the **Full Administrator** (or relevant staff group) checkbox to grant access to the settings page.
3. **Access the Module**: You can now find the manager under **Addons -> Cloudflare Manager**.

## 2. Admin Configuration Guide

Access the manager via **Addons -> Cloudflare Manager**.

### A. Global Configuration
- **Master API Token**: Enter your Cloudflare Global API Token or a Scoped Token with permissions for `Zone:Edit`, `Account:Edit`, and `DNS:Edit`.
- **Master Account ID**: Found in your Cloudflare dashboard URL (the alphanumeric string after `/dash/`).
- **Pro Addon ID**: The ID of the WHMCS Product OR Addon that unlocks "Pro" features.
- **Pro Upgrade URL**: The custom URL for the "Buy Pro" button (e.g. `cart.php?a=add&pid=X`).

### B. Client Manager (New in v2.1)
Located under the **Client Manager** tab.
- **Global Pro Toggle**: Grant or Revoke Pro status for an entire client account.
- **Account Mode Overview**: See at a glance which clients are using **Managed**, **Dedicated**, or **BYOT** modes.
- **Client Search**: Quickly find clients to manage their tier status.

### B. DNS Template Manager (The "Core" Logic)
This table defines which records are created automatically when a domain is first added.
- **Type**: Choose A, CNAME, MX, or TXT.
- **Name**: Use `@` for the root domain or specify a subdomain (e.g., `www`).
- **Content**: Use dynamic variables `{ip}` and `{domain}`.
- **Proxied**: Toggle the Cloudflare Proxy (Cloud icon) on or off for that specific record.

### C. Domain Synchronization Tool
Located under the **Domain Sync Tool** tab.
- **Selective Sync**: Manually enable or disable Cloudflare management for existing domains.
- **Status Indicators**: Instantly see which domains are 'Enabled' and managed by the addon.
- **Bulk Control**: Ensures domains hosted elsewhere or specifically excluded by the admin remain untouched. Client-area management is hidden for 'Disabled' domains.

## 2. Client Area Features

### A. Manager Dashboard (Overview)
- **Stats Dashboard**: Displays total domains, sync status, and account tier.
- **Pro Settings (Exclusive to Pro Users)**: 
  - **Account Mode Selection**: Choose between **Managed** (Admin Infrastructure), **Dedicated** (Isolated Account), and **BYOT** (Bring Your Own Token).
  - **Credential Management**: Securely store custom Cloudflare API Tokens for BYOT mode.

### B. Individual Domain Manager
- **Migration Guide**: If a domain is not yet on the infrastructure, the client is presented with a professional guide to remove it from their old account and migrate it to ours with one click.
- **DNS Editing**: Clients can now **Add, Edit, and Delete** DNS records with ease.
- **Security Toggles**: Quick access to "Under Attack Mode" and "Pause Cloudflare".
- **Purge Cache**: Immediately clears the Cloudflare cache for the entire zone.

## 3. Migration & Conflict Handling

The module features a robust **Migration Guide** for domains already active on other Cloudflare accounts.

1. **Detection**: If the API returns a conflict, the user is prompted with a Migration walkthrough.
2. **Step-by-Step**:
   - Step 1: Remove from old Cloudflare account.
   - Step 2: Wait for propagation.
   - Step 3: Click "Begin Migration" in WHMCS.
3. **Outcome**: The zone is automatically created on your master account, nameservers are updated in WHMCS, and default DNS records are pre-populated.
